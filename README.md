# Alino Billard Accessoires

Petit site vitrine React + TypeScript + Vite, données via Supabase.

## Installation

npm install
cp .env.example .env
# remplir VITE_SUPABASE_URL et VITE_SUPABASE_ANON_KEY
npm run dev

## Supabase

Exécuter supabase/schema.sql dans l'éditeur SQL Supabase, créer le bucket Storage public images.

Créer un utilisateur admin via Authentication > Users.

## Build

npm run build
